## Findings considered and rejected

Recorded so nobody re-audits them:

- Watcher-vs-spawn sync race: NOT a bug — `run_sync_pass` acquires the
  workspace `SyncLock` internally (`agent-core/src/sync_pass/mod.rs:212`);
  the `_guard` variant exists for callers already holding it.
- `remote_still_pending` hardcoded `false` in `commands.rs::do_sync`:
  by-design asymmetry — the flag is only computed for `SyncMode::Push`
  (where "push left remote work" is meaningful); full sync converges or
  reports blocked conflicts as `MirrorState::Conflict`.
- Auth middleware gaps / tunnel-relay exposure / secrets-in-logs violations:
  none found — constant-time token compare, bounded+validated relay routes,
  zeroized capabilities; terminal key display hits are intentional UX
  surfaces (`config --key`, migrate output).
- Documented dependency holds (sqlx 0.8, tokio-tungstenite 0.29,
  constant_time_eq 0.4, notify 8, spake2 0.4): intentional per root
  AGENTS.md MSRV policy; not debt.
- Pairing unit-test gap: withdrawn — `client/src/cli/pair.rs` carries 17
  test markers; coverage concern applied to tunnel e2e instead, which is
  partially covered by integration harnesses.
